# Dayday 热力图设计规范

- 状态：采用
- 日期：2026-08-09
- 适用：健康档案、记录、洞察中的时段/年度/键盘/鼠标热力图，以及菜单栏缩略热图

## 目标

热力图只表达客观聚合事实的分布，不生成健康、效率或专注评分。相同的视觉形式必须有相同的
颜色、动画和指针反馈；不同语义的数据可以使用各自的主题色，但不能重新发明一套强度档位。

本规范是依据用户提供的动画参考做出的独立 SwiftUI 实现，不复制外部产品源码或视觉素材。

## 数据与色阶

- 所有热力图采用单一连续强度色阶，不使用“低/中/高/极高”等离散聚类。
- 计数型热力图的零值使用中性、低对比底色；非零值从主题色的低透明度连续过渡到高透明度。
- 计数强度使用 `log1p(value) / log1p(maximum)`。这样既保持严格单调，也避免单个极大值把其它
  非零单元压成近似同色。
- 健康指标热力图把“无样本”显示为中性色；有样本的真实值在当前指标的观测最小值与最大值之间
  连续映射，不能把缺失日伪装成 0 BPM、0 小时等实际测量值。
- 图例必须是连续色带。计数图标出 0 与当前最大值；健康指标图标出观测最小值、最大值和真实
  单位，并明确“连续色阶”。
- 健康类型可以使用所属健康主题色；记录、输入和指针聚合默认使用当前系统强调色。

## Wave Reveal

- 只驱动一个可中断的全局进度值，不为每个单元创建计时器或异步任务。
- 波峰沿横向列推进，但单元本身做纵向上升、轻微缩放和淡入；禁止使用横向遮罩制造擦除感。
- 七行日历使用轻微行相位，让波峰形成上下起伏；最终位置必须回到稳定网格，不弹跳。
- 进入页面、重新打开菜单栏热图、切换筛选范围或数据语义时播放。稳定视图的普通后台刷新不
  应反复播放。
- “减少动态效果”开启时取消位移和缩放，只保留 0.15 秒统一淡入。
- 动画期间不得锁定输入；新的筛选或离开页面应立即取消旧任务。

## 布局

### 日历热力图

- 星期从周一开始，横向为周、纵向为星期。
- 健康档案固定展示最近 365 个自然日，不再提供 30/90/365 天热力图切换；每格表达所选健康
  指标的真实每日值，而不是该日入档记录数量。
- 单元尺寸随可用宽度连续变化：最小 4.5 pt、最大 11 pt；宽窗口不无限放大，窄窗口不默认
  退化为横向滚动。
- 月份标签与周列共用同一列宽，避免月份文字改变网格几何。

### 时段、键盘与鼠标热图

- 时段热力图沿小时列播放同一波浪；记录页仍保留用户选择的日期范围。
- 键盘按真实物理布局渲染，键名常显，准确次数通过悬浮和辅助功能文本获取。
- 鼠标热图保持归一化网格与显示器比例，不恢复或暗示原始坐标；悬浮只显示网格行列及聚合值。
- 菜单栏热图是只读缩略图，复用色阶和波浪，但不增加大型图例或浮层。

## 悬浮与可访问性

- 稠密网格默认不在单元内印数字，避免文字遮挡颜色和造成视觉噪声。
- 指针悬浮时，在稳定的读数条或原生帮助提示中显示日期/时段/区域、准确值和单位；当前单元可增加
  一条轻边框，但不改变其强度颜色。
- 全尺寸热力图必须提供文本等价：单元辅助功能标签，或默认折叠的惰性数据表。
- 颜色不是唯一信息载体；标题、单位、最大值和客观含义必须同时存在。

## 共享实现

以下类型是唯一实现入口，不允许在业务页面重新编写平方根色阶、四档图例或独立延时序列：

- `DaydayHeatmapScale`
- `DaydayHeatmapWaveMotion`
- `DaydayHeatmapWaveReveal`
- `daydayHeatmapWaveCell(...)`
- `DaydayHeatmapContinuousLegend`
- `DaydayHeatmapHoverSummary`
- `DaydayCalendarHeatmapLayout`

## 验收

1. 健康档案首次进入与切换健康指标时可见纵向起伏，不出现横向擦除。
2. 记录页切换日期范围时播放同一动画，悬浮显示准确时段信息。
3. 健康档案在常见窗口宽度内显示完整最近一年，无横向滚动，宽窗口单元不超过 11 pt。
4. 所有主热力图只有连续色带，不出现三档或四档聚类图例。
5. 鼠标悬浮可获得准确值和真实单位；离开单元后恢复提示文案。
6. Reduce Motion 下无上下位移；键盘与筛选操作在动画过程中仍然响应。
