# ADR 0106: 多指标健康瀑布流与分层趋势动画

- 状态：接受
- 日期：2026-08-09
- 关联：ADR 0104、0105

## 背景

ADR 0105 先用心率、步数和睡眠关闭了“以入档数量冒充健康指标”的问题，但本机档案已经包含更多
具有明确 HealthKit 单位的客观事实。继续只展示三个指标会把同步覆盖与首页能力割裂；同时，以单一
选中指标占据大面积热力图和折线图，使年度热力图过小、折线图过高，也迫使用户反复切换才能建立
整体认识。

## 决策

### 有界真实指标目录

仪表盘投影扩展到以下单位和指标家族；只有查询范围内真实存在记录的系列才返回到界面：

- 心脏与呼吸：心率、静息心率、心率变异性、呼吸频率、血氧、步行平均心率、心肺适能；
- 活动：步数、步行/跑步距离、骑行距离、活动/静息能量、锻炼时间、日照时间、训练；
- 睡眠与身心：睡眠、睡眠腕温、正念；
- 身体、营养和环境：体重、BMI、步行速度、饮水、耳机和环境声音暴露。

离散量按日或小时取平均并保留最近样本；累计量先按来源和绝对小时求和，再在来源间取最大值，
避免 Apple Watch、iPhone 和第三方来源的明显重叠被盲目相加；睡眠继续沿用 ADR 0105 的会话与
来源协调；训练和正念按持续时间汇总。原始事实仍是唯一真相，投影不生成目标、评分、诊断或建议。

新增类型必须明确 Companion 原始单位、规范化展示单位、平均/累计/持续时间口径和来源协调，不能
仅因档案中存在该 kind 就自动成为图表。

### 界面组合

首页保留一个可聚焦指标的全年热力图和紧凑趋势图，用于精细悬浮查看；所有可用指标同时进入下方
的响应式瀑布流，每张卡片显示所选范围的客观值和独立时间范围的紧凑趋势。点击卡片只改变上方聚焦指标，
不会隐藏其他指标，也不会修改该卡片或其他卡片的筛选范围。瀑布流以约 250pt 为卡片宽度下限，
随可用宽度在一至四列之间切换，并继续按当前列高放置，而不是退化为等高卡片网格。

卡片目录以最近 7 天作为固定的首页可用性窗口：窗口内存在有限数值的指标先展示，没有最近数据的
指标统一沉到目录底部；两组内部都保持既定指标优先级，避免刷新时无意义地乱序。该排序不跟随单张
卡片的独立筛选变化，也不把历史数据删除或误报为不存在。首屏在三列和四列宽度下至少填满两行；
“查看更多”按完整行扩展，避免少量首显卡片和不等高列把按钮推到大块空白之后。

每个趋势统一提供“昨天、当天、7 天、1 个月、3 个月、全年”六档。昨天和当天显示对应范围内
最后一个已同步客观值；7 天及更长范围的卡片主数值显示该范围平均值，不使用可能被误解为实时值的
最近样本。离散平均按每个聚合点的 `contributingSampleCount` 加权，累计量和持续时间按有事实的日点
算术平均；没有记录的日期不被伪造为零。

年度热力图获得更宽的主区域；聚焦折线图高度从原先的大型详情图降为紧凑图，瀑布流中的折线图
进一步压缩。每张趋势图按自己的当前范围计算一条低对比虚线平均值，并在虚线上直接标明平均值；
它不生成目标或健康判断。纵轴从当前可见数值生成带留白的紧凑漂亮刻度，面积填充以下界而非零作为
基线；聚焦大图的单位放在绘图区左上角，瀑布流指标卡片不重复显示纵轴单位。悬浮提示仍位于独立
overlay，不参与 Chart 布局。

### 动画语义

指标与时间范围之间的切换都保持同一 Chart 和数据点身份，让 Swift Charts 对位置、曲线和坐标域
直接插值。健康图表明确不使用弹簧，也不创建延时透明度任务；统一使用 320 毫秒的
`cubic-bezier(0.40, 0, 0.20, 1)` 平滑曲线，因此快速连续切换会从当前呈现状态重定向，不等待旧动画
结束，也不会先隐藏旧线再显示新线。任一卡片切换仍不会触发其他卡片的范围变化，且只有被修改的
Equatable 卡片重新计算范围点、平均值和坐标轴。Reduce Motion 下直接更新。

## 隐私与性能

该决策不增加授权类型、网络、遥测、AI 推断或持久化健康数值表。SQLite 先查询范围内实际存在的
类型，只为有事实的受支持指标生成最多 365 个日点和当天小时点；结果继续进入 ADR 0104 的版本化
内存缓存。每个折线图在初始化时只生成一次有界快照，供曲线、平均线、纵轴、悬浮和无障碍摘要复用，
不在单帧内重复筛选或求平均。SwiftUI 永远不接收二十万条原始事实。

## 后果

用户无需进入二级菜单即可同时回看多项健康事实，页面节奏由真实数据密度而不是等高卡片决定。
代价是每个新增指标都需要聚合与格式化测试，且真实大档案上的冷查询和滚动帧节奏仍需持续验证。
