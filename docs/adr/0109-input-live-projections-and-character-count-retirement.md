# ADR 0109: 键鼠实时投影与实际输入字数退役

- 状态：接受
- 日期：2026-08-11
- 取代：ADR 0042 的采集与展示决策；保留其历史载荷兼容部分

## 背景

洞察、托盘和 Today 的键鼠数字需要在输入后迅速更新，但旧路径把 CoreGraphics event tap 安装在主
运行循环上，并把事件逐个送入异步采集器。鼠标移动还会在采集过程中反复读取显示器拓扑。与此同时，
“实际输入字数”同时依赖辅助功能文本差分和 MarkEdit WebKit 桥接；它既不是键鼠洞察的必要指标，
又会与输入法组合、页面渲染和实时统计争抢资源。

## 决策

### 退役实际输入字数

不再采集、计算、设置或展示实际输入字数。移除辅助功能文本差分、编辑器上报、设置开关、Today、
洞察和应用详情中的相应读路径。日记与日报仍保留输入法组合、内容同步、自动保存、Markdown 预览、
选择状态及延迟装饰器重建；Return/Enter 仍可作为内容无关的提交锚点。

`InputAggregate.committedCharacterCount` 暂不移除，以便旧 SQLite payload 继续解码。所有新的小时
聚合和日汇总都写入零，所有前台投影忽略它。下一次明确的主版本数据迁移再移除该字段。

### 独立输入线程与批处理

CoreGraphics tap 由专用 `InputEventTapThread` 的 CFRunLoop 安装、启停和恢复，主运行循环不再承载
tap source。回调只提取最小瞬态事实并投递给有界邮箱；邮箱每次排空为一个批次，避免每一个系统回调
创建新的异步任务。连续鼠标移动仍只保留队列末端，按键、点击、滚动和故障边界保持顺序与失效语义。

显示器区域改为事件驱动快照：配置变化时在 utility 队列重建，指针路径只读取不可变区域快照。聚合
变化以 80 毫秒窗口向上发布；App 层以约 100 毫秒刷新内存增量。键盘或鼠标切换不触发 SQLite 查询，
鼠标网格只在鼠标视图可见时后台构建。

### 历史投影

当天继续由内存中的开放小时桶与持久化事实合并；已结束小时按既有日汇总机制压缩为日聚合。洞察模型
保持最多四个已解码范围投影，并在配置后后台预热 7 天与 30 天范围。指针日详情按需解码，并采用
32 日 LRU。缓存只包含已有的汇总，不创建新的原始输入数据；包含今天的范围短时失效，历史闭区间可
长期复用。

所有键鼠数字及条形图继续复用共享 `DaydayLiveMetricMotion` 的 snappy 过渡；Reduce Motion 仍由
现有设计系统统一降级。动画只解释已合并的状态，不随每一个原始事件创建动画。

## 开源参考与边界

设计参考了 [KeyStats](https://github.com/debugtheworldbot/keyStats) 的轻量本地键鼠统计方向，以及
[Activity Bar](https://github.com/SuveenE/activity-bar) 的范围化本地活动呈现方向。两者均为 MIT
仓库；本次没有复制其源代码，因此没有将第三方代码纳入产品。若未来直接改编任何文件，必须记录
固定 commit、保留版权与完整许可证，并更新 NOTICE。ActivityWatch 仅可作为架构阅读材料，不能把
MPL-2.0 源码复制到本工程。

## 后果与验证

- 新写入的兼容字段恒为零，旧记录仍可读取但不参与前台统计。
- 主线程不再持有 event tap source；一个输入批次只跨越一次采集 actor 边界。
- 鼠标移动和滚动会触发与按键、点击一致的实时失效通知。
- 应用启动后预热常用历史范围；键盘/鼠标视图切换复用已完成投影。
- 单元测试覆盖 IME 编辑器同步、批次邮箱顺序与溢出、采集实时失效、历史 LRU、旧载荷兼容和新载荷
  的零值写入。真实 Mac 仍需使用 Instruments 核验 P95 交互延迟与 CPU 门槛。
